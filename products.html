APEX HMS

Offline-first, multi-tenant hospital infrastructure. Unreliable connectivity, recovery, auditability and synchronisation are treated as architecture decisions from the start.

Clinical & operational coverage

Patient workflowsOPD / IPDBed managementPharmacyLaboratoryNotificationsBillingExternal integrationsRole-based accessMulti-hospital config

Architecture

  • Write-ahead log + replay is the recovery backbone. Committed intent survives a crash.
  • Single-authority job supervision. One supervisor owns state transitions; workers don't decide state on their own.
  • Offline-first sync, so work continues through network problems.
  • Multi-tenant RBAC and tamper-evident audit chains.
  • Durable outboxes for external delivery.

Shortz AI Pipeline

A local-first video generation pipeline for programmatic media production. Run it below and inject a failure to see how a broken stage is handled.

01 Script 02 TTS 03 Align 04 Subtitles 05 Render
Queue waiting · ready to run

Stack: FastAPI, Redis, XTTS, Whisper, FFmpeg, Prometheus and Grafana. API handling, GUI, workers, pipeline execution, monitoring and resource management are kept separate.

Per-stage telemetry: queue wait, processing stages, stage timing, failure classification and pipeline progress, with soak testing and failure injection. It's systems-oriented application engineering rather than a mature production service, and test coverage is uneven.
